# Reference analysis: Generative Agents

## Scope and method

This project is an independent implementation inspired by [Stanford's `generative_agents` repository](https://github.com/joonspk-research/generative_agents), not an extension or port. The findings below come from direct source inspection of the pinned snapshot `fe05a71d3e4ed7d10bf68aa4eda6dd995ec070f4`, retrieved 2026-10-18. The environment's MCP inventory did not expose REA tools in this session, so source-repository inspection was applied. The original runtime was not run; findings describe source behavior, not observed runtime outcomes.

## Verified source observations

- **Cognition sequence:** `Persona.move` updates time/location, checks a day boundary, then runs perception, retrieval, planning, reflection, and execution ([`persona.py`](https://github.com/joonspk-research/generative_agents/blob/fe05a71d3e4ed7d10bf68aa4eda6dd995ec070f4/reverie/backend_server/persona/persona.py#L185-L232)). Persona cognitive modules share and mutate scratch state and memories; they are not isolated stateless services.
- **Perception:** [`perceive.py`](https://github.com/joonspk-research/generative_agents/blob/fe05a71d3e4ed7d10bf68aa4eda6dd995ec070f4/reverie/backend_server/persona/cognitive_modules/perceive.py#L25-L130) examines nearby map tiles, stores encountered spatial addresses, observes events in the current arena, deduplicates them, prioritizes by distance, applies an attention bandwidth, and suppresses recently summarized events. This is a symbolic map/event model, not biological sensing.
- **Retrieval/memory:** basic retrieval associates newly perceived events with keyword-related events or thoughts ([`retrieve.py`](https://github.com/joonspk-research/generative_agents/blob/fe05a71d3e4ed7d10bf68aa4eda6dd995ec070f4/reverie/backend_server/persona/cognitive_modules/retrieve.py#L16-L48)). `new_retrieve` scores memories with recency, embedding relevance, and poignancy/importance, applies configured weights and global multipliers, returns top nodes, and updates access time ([`retrieve.py`](https://github.com/joonspk-research/generative_agents/blob/fe05a71d3e4ed7d10bf68aa4eda6dd995ec070f4/reverie/backend_server/persona/cognitive_modules/retrieve.py#L199-L268)). The source comments describe the weights as candidates for future learning, not learned values. Associative keyword indexes are in [`associative_memory.py`](https://github.com/joonspk-research/generative_agents/blob/fe05a71d3e4ed7d10bf68aa4eda6dd995ec070f4/reverie/backend_server/persona/memory_structures/associative_memory.py#L305-L330).
- **Planning/reflection:** planning generates daily schedules and decomposes current actions, and can react to salient retrieved events ([`plan.py`](https://github.com/joonspk-research/generative_agents/blob/fe05a71d3e4ed7d10bf68aa4eda6dd995ec070f4/reverie/backend_server/persona/cognitive_modules/plan.py#L461-L520), [`plan.py`](https://github.com/joonspk-research/generative_agents/blob/fe05a71d3e4ed7d10bf68aa4eda6dd995ec070f4/reverie/backend_server/persona/cognitive_modules/plan.py#L931-L1005)). Reflection is triggered by an importance accumulator, forms focal points, retrieves relevant memories, and stores generated insights with evidence references ([`reflect.py`](https://github.com/joonspk-research/generative_agents/blob/fe05a71d3e4ed7d10bf68aa4eda6dd995ec070f4/reverie/backend_server/persona/cognitive_modules/reflect.py#L99-L185)). Decisions are prompt-driven language-model outputs, not a reward-trained action policy.
- **Execution/pathfinding/spatial memory:** execution samples target tiles, prefers unoccupied candidates where possible, computes and stores a route, then emits one next tile per call ([`execute.py`](https://github.com/joonspk-research/generative_agents/blob/fe05a71d3e4ed7d10bf68aa4eda6dd995ec070f4/reverie/backend_server/persona/cognitive_modules/execute.py#L35-L146)). The active `path_finder_v2` is a four-neighbor distance/flood-fill routine with an iteration guard ([`path_finder.py`](https://github.com/joonspk-research/generative_agents/blob/fe05a71d3e4ed7d10bf68aa4eda6dd995ec070f4/reverie/backend_server/path_finder.py#L96-L176)). `MemoryTree` persists a semantic world/sector/arena/object address tree ([`spatial_memory.py`](https://github.com/joonspk-research/generative_agents/blob/fe05a71d3e4ed7d10bf68aa4eda6dd995ec070f4/reverie/backend_server/persona/memory_structures/spatial_memory.py)); this differs from navigation's collision grid.
- **Time and visualization:** the backend stores current time, seconds per step, and step number; each loop calls personas, saves movement/timestamp data, and advances simulation time ([`reverie.py`](https://github.com/joonspk-research/generative_agents/blob/fe05a71d3e4ed7d10bf68aa4eda6dd995ec070f4/reverie/backend_server/reverie.py#L77-L95), [`reverie.py`](https://github.com/joonspk-research/generative_agents/blob/fe05a71d3e4ed7d10bf68aa4eda6dd995ec070f4/reverie/backend_server/reverie.py#L367-L407)). The Django/Phaser browser polls for movement and animates agents tile-by-tile ([`main_script.html`](https://github.com/joonspk-research/generative_agents/blob/fe05a71d3e4ed7d10bf68aa4eda6dd995ec070f4/environment/frontend_server/templates/home/main_script.html#L44-L80), [`main_script.html`](https://github.com/joonspk-research/generative_agents/blob/fe05a71d3e4ed7d10bf68aa4eda6dd995ec070f4/environment/frontend_server/templates/home/main_script.html#L368-L435)). The repository README describes OpenAI API-key setup and cost/rate-limit caveats ([setup](https://github.com/joonspk-research/generative_agents/blob/fe05a71d3e4ed7d10bf68aa4eda6dd995ec070f4/README.md#L10-L19), [API caveat](https://github.com/joonspk-research/generative_agents/blob/fe05a71d3e4ed7d10bf68aa4eda6dd995ec070f4/README.md#L80-L88)).

## How this MVP adapts those ideas

These are design decisions informed by the source, not claims about the source's empirical quality.

| Reference concept | MVP treatment |
| --- | --- |
| Perception → retrieval → decision → action sequence | **Adopted in simplified form:** explicit typed boundaries (`perceive`, `retrieve`, feature encoding, policy, navigation, physiology). Unlike the reference's shared mutable scratch object, the MVP uses immutable state snapshots and side-effect-free policy inference. |
| Individual event memory and relevant recall | **Replaced:** bounded per-animal event lists and transparent deterministic recent task-marker retrieval, rather than associative keyword/embedding/importance-ranked thought retrieval. |
| Prompt-based plans and reflection | **Omitted/replaced:** a locally trained categorical neural policy selects one action from 20 fixed numeric inputs; no LLM, generated narrative, daily schedule, reflection subsystem, or generated thought memory. The policy is shared across all five animal states. |
| Spatial memory, movement, pathfinding | **Simplified/replaced:** no persistent semantic spatial memory tree; current world geometry is directly observable, and deterministic grid BFS resolves action intents to at most one legal step. |
| Discrete time and browser map | **Adapted:** explicit step/pause/speed controls, seeded replay, a local standard-library HTTP API, and a canvas map with inspection and event log. This is not the reference's Django/Phaser polling implementation. |
| Reference's model/API integration | **Omitted:** local NumPy inference/training and strict local checkpoint validation; no hosted inference calls or OpenAI API key. |

The reference has no cattle physiology, feed/water dynamics, cattle-specific reward, or cattle policy training. This MVP's physiology, rewards, memory semantics, and animal actions are synthetic engineering choices. The reported 97% versus 14% training result and five passing paired-memory checkpoint checks are results on the fixed toy task only; they do not validate animal cognition or behavior. The Python source was inspected directly because REA tools were unavailable; no original runtime run was performed.
